# Road Accident Analysis Using Data Science and Machine Learning

##  Overview

This project analyzes historical road accident data using Data Science, Exploratory Data Analysis (EDA), and Machine Learning. It identifies accident patterns and predicts accident severity based on factors such as time, weather, lighting, and road conditions.

##  Objectives

* Analyze road accident patterns and trends.
* Identify factors associated with accident severity.
* Build and compare machine learning models.
* Handle class imbalance and evaluate model performance.
* Develop an interactive dashboard for data exploration and severity prediction.

## Methodology

1. **Data Preprocessing:** Handle missing values, duplicates, and inconsistent data.
2. **EDA:** Analyze accident patterns using visualizations.
3. **Machine Learning:** Implement and compare Random Forest, XGBoost, and LightGBM.
4. **Evaluation:** Use accuracy, precision, recall, F1-score, confusion matrix, and cross-validation.
5. **Dashboard:** Present accident insights and severity predictions interactively.

## Technologies Used

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* XGBoost and LightGBM
* Streamlit
* Git and GitHub

## Future Scope

* Improve the prediction of serious and fatal accidents.
* Incorporate more recent accident data.
* Use explainable AI to understand important prediction factors.
* Enhance the dashboard with additional visualizations.

##  Disclaimer

This project is intended for educational and analytical purposes. It predicts accident severity based on available conditions and does not predict whether an accident will occur.
